## 먼저 들을 순서 (P0 강의, 선후관계 기준 추천)

이력서/면접이 임박했다면 1~4번을, 백엔드 실무 역량 강화가 우선이면 5번부터 진행 권장.

1. **CS 면접 압축 정리**: 기출로 대비하는 개발자 전공면접 [CS 완전정복] → 채널톡 CS 면접대비 Java편 → 채널톡 CS 면접대비 데이터베이스편 → 외워서 끝내는 네트워크 핵심이론(기초) → 모든 개발자를 위한 HTTP 웹 기본지식 → 개발자를 위한 컴퓨터공학1(컴구조+OS)
2. **이력서/면접 실전**: 10000장의 이력서를 본 기술이사의 이력서 가이드 → N,000번의 면접을 본 기술이사의 면접 가이드
3. **RDB 기본기**: Real MySQL 시즌1 Part1 → Part2 → 비전공자도 이해할 수 있는 MySQL 성능 최적화(SQL튜닝편) → 10,000++억의 데이터를 다루는 카카오 면접관의 MySQL → 실전! 데이터베이스 완전정복[설계편]
4. **코드 품질/설계 기본기**: Readable Code → 오브젝트-설계원칙편 → 코딩으로 학습하는 GoF의 디자인 패턴 → 코딩으로 학습하는 리팩토링 → 토비의 클린 스프링(도메인모델패턴/헥사고날)
5. **백엔드 시스템 설계 실전**: Java/Spring 주니어 개발자를 위한 오답노트 → 가장 쉬운 동시성 문제-Race Condition → 스프링부트로 직접 만들면서 배우는 대규모 시스템 설계-게시판 → -캐시전략 → 장애를 허용하는 견고한 시스템 만들기 → 견고한 결제 시스템 구축 → 스프링 시큐리티 완전정복
6. **메시징/캐시**: 핵심만 빠르게 끝내는 실전 카프카 → 아파치 카프카 애플리케이션 프로그래밍 → 2026년! 백엔드 개발자를 위한 Redis 실전 가이드
7. **MSA**: 비전공자도 이해할 수 있는 MSA 입문/실전 → 카카오 면접관이 알려주는 MSA 관점에서의 분산 트랜잭션 패턴(SAGA)
8. **인프라/DevOps**: 비전공자도 이해할 수 있는 쿠버네티스 입문/실전 → 비전공자도 이해할 수 있는 Nginx 입문/실전 → 실전! GitHub Actions으로 CI/CD 시작하기 → 비전공자도 이해할 수 있는 CI/CD 입문·실전
